# Fonts of the landing page

Self-hosted, latin subset, no request to a third party at runtime.

- `anton-latin.woff2`: Anton Regular (400) by Vernon Adams, SIL Open Font License 1.1. Latin subset as packaged by
  Fontsource (`@fontsource/anton`, file `latin-400-normal.woff2`), https://fontsource.org/fonts/anton. The headlines of
  index.html and heatmap.html.
- `signika-latin.woff2`: Signika (variable, 300-700) by Anna Giedryś, SIL Open Font License 1.1, from Google Fonts,
  https://fonts.google.com/specimen/Signika. The running text.
